# Pokemon-Card-Sorter
 Modified Nolan Amblards Code to include support for every card until Stellar Crown, and implemented arduino communication to connect the card recognition script into supporting card sorting capabilities. Scanner uses a hashing method and finds the difference between a certain threshold to determine whether a card matches. Initial bounding box is found using You Only Look Once (YOLO), then hashing is performed. MySQL and creation of a database are required to run the script. The plan is to release a low cost open-source automated pokemon card sorter. Video demonstration can be found at this link. https://youtu.be/Kczf9Zbp_O0
